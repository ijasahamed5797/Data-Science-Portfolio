# 🧠 EduCognia — Cognitive Engagement Detection System

**Tools:** Python, XGBoost, Streamlit, Behavioral Analytics

EduCognia is a **real-time machine learning system that detects learner cognitive engagement using sensor-free behavioral interaction signals**.

Unlike traditional engagement detection systems that rely on intrusive sensors such as webcams or eye-tracking devices, EduCognia analyzes:

• mouse movement patterns
• keyboard typing activity
• idle time
• window switching behavior
• application usage

to infer engagement levels during online learning sessions.

🏆 **2nd Place — National Data Science Competition**

### Key Features

• Behavioral feature engineering from interaction logs
• XGBoost engagement classification model
• Real-time cognitive state prediction
• Focus score for interpretable engagement measurement
• Streamlit dashboard for live monitoring
• Application usage analytics and session history

🔗 **Project:**
[EduCognia](./EduCognia)
